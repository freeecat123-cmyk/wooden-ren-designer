## 開發順序與驗收要求（本專案建議，非官方規定）

1. 已取得當日官方列示題本及完整評審表，並記錄版本、檔案雜湊與兩套頁碼；未來發布前再檢查入口是否有更新。
2. 第一題逐張放大工作圖及剖面，建立尺寸證據表：零件 ID、完成尺寸、毛料、榫孔座標、圖號、頁碼、待確認事項。
3. 六題先做差異矩陣，再決定共用結構；不要先假設六題可用同一模型改幾個數字。
4. 先建一題經核對的固定尺寸基準。練習變更另行標示，不讓快速風格、組裝模式或縮放默默改掉考題要求。
5. 木釘／螺釘作為五金或現成零件，區分供料與實際使用，未標定位置不能憑數量平均排孔。
6. 同一模型輸出 3D、三視圖、零件圖、材料單。材料頁維持 3D 與選取連動。
7. 測試涵蓋尺寸閉合、榫孔配對、穿模、每端榫長只算一次、毛料利用、組裝順序、儲存重開與列印比例。
8. 圓角／倒角／螺釘若僅文字表示，明確列為未建模細節，不宣稱完整精確還原。
9. 完整評分表雖已取得，但逐欄核對前不發布自動判分、及格判定或扣分公式。
